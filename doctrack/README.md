# Сроки документов

Мини-приложение для отслеживания сроков личных документов.
Адрес: **https://an-mish.github.io/doctrack/**

## Что умеет

- Добавить документ: тип, название, дата выдачи, дата окончания, срок, за который начать обновление (дни / недели / месяцы), заметка.
- Статусы: «В порядке» → «Пора обновлять» → «Истёк». Сортировка по ближайшей дате.
- База хранится в **Google Таблице на вашем Google Диске**. На устройстве лежит копия, чтобы список открывался без интернета.
- Скрипт таблицы каждый день проверяет сроки и **присылает письмо на вашу почту Gmail** (и, по желанию, сообщение в Telegram).
- Скрипт сам ведёт в **Google Календаре** отдельный календарь «Сроки документов»: для каждого документа события
  «Начать обновление» и «Истекает» с напоминанием накануне в 9:00. События обновляются при каждом изменении.

Пока Google Диск не подключён, данные хранятся только в браузере.

## Подключение Google Диска (один раз, ~5 минут)

1. Откройте [sheets.new](https://sheets.new) — создастся новая Google Таблица. Назовите её, например, «Сроки документов».
2. В таблице: **Расширения → Apps Script**. Удалите текст в редакторе и вставьте всё содержимое файла
   [`google-apps-script/Code.gs`](google-apps-script/Code.gs). Нажмите 💾 «Сохранить».
3. Вверху выберите функцию **`setup`** и нажмите **«Выполнить»**.
   Google попросит разрешения: «Проверить разрешения» → выберите аккаунт →
   «Дополнительные настройки» → «Перейти на страницу …(небезопасно)» → «Разрешить».
   Это ваш собственный скрипт, Google просто не проверял его, как публичное приложение.
4. Внизу, в «Журнале выполнения», появится **ключ доступа** — длинная строка. Скопируйте её.
5. **Начать развёртывание → Новое развёртывание** → ⚙️ тип **«Веб-приложение»**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все**.

   Нажмите «Начать развёртывание» и скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. В приложении: меню «⋯» → **«Google Диск»** → вставьте URL и ключ → «Подключить».
   Документы, которые уже были на устройстве, перенесутся в таблицу.

На каждом новом устройстве (телефон, компьютер) повторите только шаг 6.

Проверить письмо: в редакторе Apps Script выберите функцию **`testReminder`** → «Выполнить».
Письмо придёт, если есть документы, которым пора обновиться.

### Безопасность

«Доступ: Все» означает, что адрес скрипта открыт, но без ключа он ничего не отдаёт и не меняет.
Ключ — 64 случайных символа, он хранится только в настройках скрипта и в браузере на ваших устройствах.
Не публикуйте URL вместе с ключом. Если ключ утёк: в Apps Script → ⚙️ «Настройки проекта» →
«Свойства скрипта» удалите `API_KEY`, снова выполните `setup` и введите новый ключ в приложении.

### Таблицу можно редактировать вручную

Лист «Документы»: столбцы «Тип», «Название», «Дата выдачи», «Действует до», «Начать обновление за»,
«Единица» (дней / недель / месяцев), «Заметка». Добавленные вручную строки появятся в приложении
(первый скрытый столбец `id` заполнится сам). Строки без названия или даты окончания пропускаются.

### Если поменяли `Code.gs`

После правки кода: **Развёртывания → Управление развёртываниями → ✏️ → Версия: «Новая версия» → Развернуть**.
URL при этом не меняется.

## Напоминания

- **Почта** — приходит сама, ежедневно около 9:00 (по часовому поясу таблицы): в первый день окна обновления,
  за 60/30/14/7/3/1 день до окончания, в день окончания и по понедельникам, пока документ не обновлён.
- **Telegram (по желанию)** — создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot` → токен),
  напишите боту любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
  `"chat":{"id": ...}`. В Apps Script → ⚙️ «Настройки проекта» → «Свойства скрипта» добавьте
  `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Сообщения будут приходить вместе с письмами.
- **Уведомления браузера** — кнопка «Включить» в приложении; приходят при открытии приложения.
  На iPhone сначала добавьте сайт на экран «Домой» (Safari → «Поделиться» → «На экран „Домой“»).
- **Google Календарь** — автоматически, если подключён Google Диск (календарь «Сроки документов»).
  На iPhone он появится в приложении «Календарь», если там добавлен ваш Google-аккаунт
  (Настройки → Календарь → Учётные записи).
- **Календарь вручную** — меню «⋯» → «Добавить в календарь (.ics)»: события «Начать обновление» и «Истекает»
  с напоминанием в 10:00.
