# Сроки документов

Мини-приложение для отслеживания сроков личных документов.
Адрес: **https://an-mish.github.io/doctrack/**

## Что умеет

- Добавить документ: тип, название, дата выдачи, дата окончания, срок, за который начать обновление (дни / недели / месяцы), заметка.
- Статусы: «В порядке» → «Пора обновлять» → «Истёк». Сортировка по ближайшей дате.
- Данные хранятся только в браузере на устройстве (localStorage). Есть резервная копия в JSON и восстановление из неё.

## Как получать напоминания

Есть три способа, их можно совмещать.

### 1. Уведомления браузера
Нажмите «Включить» в приложении. Уведомление приходит при открытии приложения
(раз в день на каждый документ, которому пора обновиться). В Chrome на Android установленное
приложение может проверять сроки и в фоне, но браузер делает это не гарантированно.

На iPhone: откройте сайт в Safari → «Поделиться» → «На экран „Домой“», запустите
приложение с иконки и включите уведомления там.

### 2. Календарь (надёжно, без настроек)
Меню «⋯» → «Добавить в календарь (.ics)». Для каждого документа создаются два события:
«Начать обновление» и «Истекает», с напоминанием в 10:00 того дня. Откройте файл на телефоне —
события добавятся в календарь и уведомление придёт, даже если приложение не открыто.
После изменения документов выгрузите файл заново.

### 3. Telegram (надёжно, сообщения приходят сами)
Каждый день в 09:07 по Москве GitHub Actions проверяет сроки и присылает сообщение:
в первый день окна обновления, за 60/30/14/7/3/1 день, в день окончания и каждый понедельник,
пока документ не обновлён.

Настройка (один раз):
1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` — это **chat id**.
3. В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**, создайте:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — chat id;
   - `DOCS_JSON` — строка из приложения: меню «⋯» → «Напоминания в Telegram» → «Скопировать».
4. Проверка: **Actions → Document reminders → Run workflow**. Сообщение придёт, если есть документы в окне обновления.

Секреты зашифрованы и не видны в публичном репозитории. В `DOCS_JSON` попадают только название,
тип, дата окончания и срок напоминания — без номеров и заметок. После изменения списка документов
обновите секрет `DOCS_JSON`.

Важно: GitHub отключает расписание в репозиториях без активности 60 дней — если сообщения
перестали приходить, зайдите в Actions и включите workflow снова.
