# Прайс косметолога

Мобильное приложение (PWA) для расчёта себестоимости и цены услуг косметолога.
Открыть: https://an-mish.github.io/kosmetolog/ → в браузере телефона «Поделиться → На экран „Домой“» (iPhone) или «Установить приложение» (Android).

**Формула** (как в исходной таблице Notion):

- Час работы = сумма постоянных затрат в месяц ÷ рабочих часов в месяц
- Время = длительность + пауза × 50 % (доля паузы меняется в настройках)
- Постоянные затраты услуги = час работы ÷ 60 × время
- Материалы = Σ (цена упаковки ÷ объём упаковки × расход)
- Цена = (постоянные затраты + материалы) × (1 + наценка %), с округлением по выбору

Данные хранятся в браузере телефона; копию можно сохранить и загрузить в «⚙︎ → Данные».
