# Прайс косметолога

Мобильное приложение (PWA) для расчёта цен на услуги косметолога.
Открыть: https://an-mish.github.io/kosmetolog/ → «Поделиться → На экран „Домой“» (iPhone) или «Установить приложение» (Android).

## Как устроен расчёт

1. **Мои цифры** — расходы кабинета в месяц (без зарплаты), сколько хочу получать на руки, сколько часов в месяц занято клиентами.
2. **Закупки** — каждая покупка вносится с ценой упаковки и количеством в ней. Цена позиции берётся из последней закупки; история сохраняется.
3. **Пакеты** — наборы мелочей на процедуру (шапочка, простыня, перчатки, диски…), собираются из позиций; стоимость считается сама.
4. **Услуги** — время (процедура + пауза), пакеты и косметика с нормой расхода («мл на процедуру» или «процедур из упаковки»).

Для каждой услуги:

- **Минимум** = расходы за время процедуры + расходы за паузу (только статьи, отмеченные «и в паузе») + материалы (ниже — убыток)
- Расходы «на процедуру» (стирка) = сумма в месяц ÷ число таких процедур в месяц, только для отмеченных услуг
- **В ноль** = минимум + ваш доход за процедуру и паузу
- **Рекомендуемая** = «в ноль» + запас % (по умолчанию 15 %), округлено вверх

Данные хранятся в браузере телефона; копию можно сохранить в «Мои цифры → Данные».
